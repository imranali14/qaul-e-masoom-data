# Qaul-e-Masoom — data

This public repository hosts the **hadith database** that the Qaul-e-Masoom Android app downloads
(in [Releases](../../releases): `manifest.json` + `qaul-e-masoom-<version>.db.gz`), and the app's
[privacy policy](https://imranali14.github.io/qaul-e-masoom-data/privacy/).

- Arabic texts: classical works. English translations: thaqalayn.net and their translators (used with permission).
- AI translations inside the database are marked as AI (`translation_source = 'ai'`) until reviewed.
- Each release lists the SHA-256 of the database; the app checks it before use.
